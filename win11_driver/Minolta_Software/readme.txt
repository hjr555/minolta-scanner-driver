Thank you for purchasing the MINOLTA DiMAGE Scan Dual III. 
This Read Me file discusses aspects of the DiMAGE Scan Dual III software not 
discussed in the manual.
Please read the manuals along with this document before operating the scanner.


* Operating Environment

TWAIN data source
Some applications may have problems if a TWAIN source is opened while another 
TWAIN source (DiMAGE Scan Dual III software) is already activated.  
Do not open a TWAIN source on top of an existing TWAIN source.

Some applications can be operated while the TWAIN data source (DiMAGE Scan Dual III 
software) is active. Once opened through an application, the DiMAGE Scan Dual III 
software may not be operated if the host application is closed while the utility 
remains open. Always close the DiMAGE Scan Dual III software before closing 
the host application. Never open the DiMAGE Scan Dual III software through 
an application and by itself at the same time.

Free space on startup disk
Make sure that you have the recommended amount of free space on the startup disk 
before scanning.
If there is not enough space in the startup disk, an error may occur during the scan.

The free space required for the built-in memory or the hard disc on Windows

- 8bit scan,	Auto Dust Brush and Pixel Polish are off,	64MB,	approximately 100MB
- 16bit scan,	Auto Dust Brush is off,				64MB,	approximately 200MB
- 8bit scan,	Auto Dust Brush and Pixel Polish are on,	128MB,	approximately 300MB
- 16bit scan,	Auto Dust Brush is on,				128MB,	approximately 500MB



* Scan Settings

Scan Setting Values
There may be slight errors in the Input Resolution, Scaling, and Input Size values 
due to precision errors.

Image Size
"Image Size" is calculated from actual pixel count of the scanned image. 
- The actual file size will vary depending on the file format in which the image 
is saved, and may differ from the one displayed in the "Image Size".


* Scanning

Image Correction and Exposure Control
When significant changes have been made with the image correction or 
exposure control tab, the resulting scanned image may differ slightly from 
the preview image. When using image correction or exposure control, 
the scan time may increase.
Depending on the image, the auto-setting function in the image-correction 
palettes may not seem to have any affect on the image.
The numeric values inputted into a text box in an image-correction palette is set 
when another text box, button, or slider is clicked.

Color Reproduction of Negative Film
When using 35mm, make sure that the film is aligned correctly with the film 
holder frame. This is necessary to ensure that the AE (Automatic Exposure) 
can be performed correctly.  
Misaligned film may produce unexpected color casts in the scanned image.

Scanning multiple images
When scanning multiple images sequentially by the TWAIN data source 
(DiMAGE Scan Dual III software), scan speeds of subsequent images may be 
slower than the first image, depending on memory configuration.  
The maximum number of images which can be simultaneously scaned in 
some applications may be limited depending on PC configuration.
In such cases, use of DiMAGE Scan Dual III Utility is recommended.

Monitor Gamma
If "Color Matching ON" checkbox is not checked in the Preference Dialog Box of 
the TWAIN-Driver DiMAGE Scan Dual III software, set the Monitor Gamma at 2.2 
on the host application in use.

If the PC is quit forcibly or incorrectly
If the PC is quit forcibly or incorrectly while the scanning is performed, 
the file for the operation may remain in the hard disc.  In this case, 
delete the following folder.
The file to be deleted: in the [Windows] folder -> the [Raw****.tmp] file 
in the [Temp] folder (The **** part of the file is the number.)
