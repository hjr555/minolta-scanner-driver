THE FINAL SCAN

After setting the scanner settings, the final scan can be made. The scanned image can be saved in one of the following file formats:
  • JPEG
  • TIFF
  • BMP (Windows only)
  • PICT (Macintosh only)
16-bit images can only be saved in the TIFF format.

<When using the scanner utility through an image-processing application>

  1. Click the scan button in the main window make the final scan.
  2. Save the image through the application software.

<When using the scanner utility software only>

  1. Click the scan button in the main window.
    • The operating system's save dialog box will appear.
  2. Enter the file name and select the file destination.
  3. Select the file type from the drop-down list.
  4. Click "OK."
    • The final scan will begin.
    • When multiple images are scanned at one time, they are saved with a serial number attached to the file name: File_Name001, File_Name002, File_Name003...
