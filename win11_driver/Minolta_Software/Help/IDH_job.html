JOBS

WHAT IS A JOB?

A Job is a predetermined set of input and output scan settings that optimizes the scanner for specific uses and specific film types. The DiMAGE Scan Dual III contains approximately 110 Job files to cover a wide range of image use. Jobs can also be created for specific situations that the user encounters frequently. Job files for 35mm-film images are stored in the following ten catagories:

Custom:
User-created scan settings.

Color Laser Printer:
Digital color copiers and color laser printers. Uses an output resolution of 600dpi with four paper sizes from A4 quarter to letter eighth.

Photosensitive:
Printers that use photosensitive or photographic material. Use an output resolution of 400 dpi with six paper sizes from A5 full to 4X6 postcards.

Ink Jet & Dye-Sub Printer:
Ink Jet and Dye-sublimation printers. Uses an output resolution of 300 dpi with ten paper sizes from A4 full to 3X5 photo.

Photo CD:
For the photo CD format. Uses an output resolution of 300 dpi with three image sizes: 2048 X 3072, 1024 X 1536, and 512 X 768.

Web Page:
For use on the world-wide web. Uses an output resolution of 72 dpi with seven image sizes from 320 X 240 to 1280 X 836.

Screen:
For monitor display. Uses an output resolution of 72 dpi with nine image sizes from 640 X 480 to 1920 X 1200.

Document:
For an image to be embedded in a document. Uses an output resolution of 72 dpi with six paper sizes from letter eighth to A4 half.

Film Recorder:
For high resolution images from a film recorder. Image size is 2028 X 1365.

Default:
This category uses the scanner default settings. Uses an output resolution of 300 dpi.

HOW TO SAVE A JOB

  1. Set the input and output scan settings.
  2. Click the save Job button.
    • The Job registry dialog box will appear.
  3. Name the job and select the category. Click "OK" to save the Job.

LOADING A JOB

  1. Click the load Job button.
    • The Job selection dialog box will appear.
  2. Select the Job category from the pull-down list.
  3. Click the Job name. Click "OK" to load the Job.
    • The settings are displayed with the index scan or prescan.
    • The job names can be listed chronologically or alphabetically. Sort the list by clicking on the name or date radio buttons.
