PREFERENCES

The following items can be set in the preferences dialog box:
  • Exposure control for negative
  • Auto exposure options for slide film.
  • Close the utility after scanning.
  • Autofocus at scan.
  • Color depth
  • Multi-sample scanning
  • Index scan priority
  • Rotate all frames 180 degrees (for APS film only).
  • Color matching

EXPOSURE CONTROL FOR NEGATIVE

Used to select the AE system to scan negative film. There are two AE systems: Auto and Manual. Select the desired radio button.
When Auto is selected, the film information is read, and exposure is automatically corrected and color balance is controlled.
When Manual is selected, the existing exposure collection value is used; therefore, use the exposure control tab to adjust the amount of exposure.

AUTO EXPOSE FOR SLIDES

Since well exposed slides are uniform in density, auto exposure control is not needed when scanning. However, when a slide is over or underexposed, the auto exposure system can compensate for the unusual density. Simple click the check box before scanning the slide film. To use the AE lock or AE area selection functions with slides, the auto-expose-for-slides option must be checked.

CLOSE UTILITY AFTER SCANNING

Checking this option closes the Standard Scan Utility after the final scan. When the scanner is opened through an image-processing application like Adobe Photoshop Elements, this function allows the image to be scanned and then processed directly in the image-processing application. However, uncheck the box when multiple images need to be scanned before retouching.

AUTOFOCUS AT SCAN

Checking this option activates the autofocus system during the prescan and final scan. The autofocus-at-scan option increases the scanning time.

COLOR DEPTH

This option specifies the color depth of the scanned image. Three options are available: 8 bit, 16 bit, and 16-bit linear. 16-bit linear does not make any gamma corrections so a scanned negative will produce a negative image. 16-bit and 16-bit linear images can only be saved as TIFF files. Some image-processing applications, like Adobe Photoshop Elements, cannot process 16-bit image files.

MULTI-SAMPLE SCANNING

Multi-sample scanning reduces random noise in the image by analyzing the data of each sample scan. The more samples taken, the less random noise and the longer the scanning time. There are five multi-sample settings: off, 2X, 4X, and 8X.

INDEX SCAN PRIORITY

This option allows the selection of high-speed index scans or quality index scans with prescans. Simply click the appropriate radio button.

The speed scan option only creates index thumbnails. The scanner will make separate scans when prescans are required.

The quality scan option creates index and prescan images at the same time. Double clicking on the index thumbnail will immediately display the prescan image. Prescan images are easier to evaluate than index thumbnails and only prescans can be corrected using the scanners image processing tools. Quality index scans increase scanning time.

ROTATE ALL INDEX FRAMES 180 DEGREES - FOR APS FILM ONLY

Simply click the check box to rotate the APS index images 180 degrees.

COLOR MATCHING

Each output device (monitor or printer) defines color and contrast differently. To ensure the reproduction of the image on the monitor matches the reproduction of the image from the printer, the color space for both devices must be defined.

The scanner's color matching function matches the color and contrast of the scanned image with the specified output color space. The color matching system can use the monitor's ICC profile to display the image as accurately as possible.

<How to set output color space>

  1. Click the color-matching-on check box.
  2. Choose the color space from the color-space list box.

<How to set the monitor's ICC profile>

  1. Click the use-ICC-profile check box.
  2. Click the load button.
    • The standard open dialog will be displayed.
  3. Select your monitor's ICC profile.
    • The ICC profiles can be found in the following locations:
      Macintosh: [System folder] > [ColorSync profile folder].
      Windows 98/98SE/Me: [Windows] folder > [System] folder.
      Windows 2000/XP: [WINNT] folder > [System32] folder > [spool] folder > [drivers] folder.

When the color-matching function is active, the other color-matching functions of the computer's operating system, video card, etc. are disabled. Some applications have a monitor-correction-display function, which automatically corrects the monitor display to a specific color space. The following are recommendations for output color space and ICC profile settings with image-processing software:

With an application with a monitor-correction-display function such as Adobe Photoshop ver. 5 or ver. 6:

  • Use the same color space as the application. With Photoshop ver. 5.0 or later, look in the color setting option in the file menu for the profile setup dialog box.

  • Use the ICC profile of the monitor in use.

With an application without a monitor-correction-display function such as Adobe Photoshop Elements, or when the function is turned off:

  • Select "Monitor RGB" for the output color space.

  • Use the ICC profile of the monitor in use.
