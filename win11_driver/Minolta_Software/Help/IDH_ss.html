SCAN SETTINGS

INPUT RESOLUTION LIST BOX

Values can be selected from the drop-down list or entered directly into the box. The resolutions on the list are 2820, 1410, 940, 705, 470, 352, and 282. The default setting is 705.

OUTPUT RESOLUTION LIST BOX

Values can be selected from the drop-down list or entered directly into the box. The output resolution options are 2400, 1440,1200, 800, 720, 600, 400, 360, 350, 300, 240, 200, 180, 150, 96, 72, and 36 dpi. Values between 36 and 2400 can be enter into the box. The default setting is 300 dpi. The output resolution list box cannot be selected while "pixel" is selected in the unit list box.

INPUT SIZE TEXT BOX

The input size is related to the the cropping frame. As the cropping frame is adjusted the input size will change. Entering values for the input size will adjust the cropping frame to the new dimensions. The input size text box cannot be used while "pixel" is selected in the unit list box.

Click the lock button next to the input size text box to set the dimensions. The cropping frame can be moved when the input size is locked, but it cannot be resized. Clicking the button again releases the lock.

MAGNIFICATION TEXT BOX

The magnification of the input image to the output image is set in this box. Magnification is calculated by the input resolution divided by the output resolution, or the output size divided by the input size.

When the input and output size are not locked, the input resolution and output size vary according to the magnification value entered. When the output size is locked, the input resolution and size will vary with the change in magnification. When the input size is locked, the input resolution and output size vary with the change in magnification. Magnification cannot be adjusted when "pixel" is selected in the unit box.

OUTPUT SIZE TEXT BOX

The output size is related to the size of the cropping frame, and the input and output resolution. The width and height of the image can be directly entered into the text boxes; the input resolution and size, and the cropping frame will adjust accordingly.

The output size can be locked by clicking the lock button next to the text boxes. The cropping frame can be resized, but its dimensions will be proportional to the output size. When adjusting the cropping frame the input resolution and size adjust accordingly. Clicking the button again releases the lock.

UNIT LIST BOX

The unit of the input and output sizes can be specified: pixels, millimeters, centimeters, inches, pica, and point. The default setting is pixels.

IMAGE SIZE DISPLAY

The image size display indicates the file size of the image based on the scanner settings.

RESET BUTTON

This initializes all current settings.
