INDEX SCANS

An index scan displays thumbnails of all the frames in the film holder.
Index scans can be made with the film holder, slide mount holder, or the optional APS adapter.
Two index-scan modes are available: high-speed and quality. These are selected in the preferences dialog box.

MAKING INDEX SCANS

  1. Click the index-scan button in the main window.
    • The index scan will begin. The previously displayed index images will be deleted.
    • The frame number on the index images refers to the film-holder frame numbers and not the frame numbers on the film.
    • Index scan thumbnails are saved until another scan is made with another film.

RESIZING THE UTILITY WINDOW

Click and drag the edge of the utility window to resize. When changing the size of the main window, the position of the index frames will change accordingly. The size and shape of the frames will not change. The size of the index frames will be automatically adjusted to the window size when the fit-to-window button is clicked (see below).

SELECTING INDEX FRAMES

Simply click on the thumbnail to select the image.

<Selection short-cuts>

    • Select multiple frames by holding the Ctrl key (Windows) or the command key (Macintosh).
    • Select consecutive frames by holding the shift key while clicking on the first and last frame in the series.
    • Select all frames by pressing the Ctrl key (Windows) or the command key (Macintosh) and the "A" key.
    • Reset all the frames by pressing the Ctrl key (Windows) or the command key (Macintosh), shift key, and the "R" key.

REVERSING THE INDEX FRAME ORDER

Some cameras reverse wind the film so the last frame is exposed at the beginning of the roll. The order of the index images can be reversed to correct the chronology by simply clicking the reverse-frame-order button.

ROTATING INDEX SCANS

The selected index frames can be rotated to be displayed correctly. Simply press the rotate right button to rotate the images 90 degrees clockwise or press the rotate left button to rotate the images 90 degrees counterclockwise.

REVERSING INDEX SCAN IMAGES

The selected index frames can be reversed to create a mirror image. Simply press the flip-vertical button to reverse the images from top to bottom or press the flip-horizontal button to reverse the images from left to right.

FIT-TO-WINDOW BUTTON

This function automatically resizes the index thumbnails to fit the utlity window. As the window is resized, the thumbnails will be enlarged or reduced accordingly. Simply click the fit-to-window button to activate the function.

SAVING THE INDEX SCAN THUMBNAIL IMAGES

The index thumbnails can be saved as an image file. All the thumbnail images are saved in one file.

<How to save the index thumbnails>

  1. Click the save index-scan button.
  2. Select the file format in the save-as dialog box.
    • Windows: BMP or JPEG
    • Macintosh: PICT or JPEG
  3. Input the file name and click "OK."
    • The displayed index thumbnails can be saved even though the original film is not in the scanner.

SAVING AN INDEX FILE

The index thumbnails can be saved as an index file.

<How save an index file>

  1. Click the save index-file button.
  2. Input the file name and click "OK."
    • The displayed index thumbnails can be saved even though the original film is not in the scanner.

LOADING AN INDEX FILE

An index file can be reloaded into the utility window. The new file will replace the displayed index images.

<How to load an index file>

  1. Click the load index-file button.
  2. In the open dialog box, select the index file. Click "OK" to load the file.

LOADING IMAGE-CORRECTION JOBS

A registered image-correction Job can be loaded. Although the loaded image-correction job is applied to the selected frame, the effect of the Job can only be seen on the prescan image and not on the index thumbnail.

<How to load an image-correction job>

  1. Select the image to be corrected.
  2. Click the load image-correction Job button.
    • The select-image-correction-Job dialog box will open.
  3. Click on the Job thumbnail to select it. Click "OK" to apply the job to the selected image.
