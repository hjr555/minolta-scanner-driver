PIXEL POLISH

The Pixel Polish function automatically correct images appropriately for each image. Corrections performed prior to pressing the Pixel Polish button are all reset.

<Procedure>

  1. Press the Pixel Polish button in the main window.
    • The Pixel Polish tab becomes active.
  2. Click the Pixel Polish tab to open the tab.
  3. Select a correction setting.
    • When the setting is changed, other image corrections are all reset and then Pixel Polish is executed and a simulated image is displayed.
  4. When Scene select is selected for the correction setting, select a scene keyword.
    • The Pixel Polish simulation image is displayed in accordance with the selected scene keyword.

APPLYING CORRECTION SETTING TO ALL FRAMES

Pressing the Apply all frames button applies the current setting to all frames.
The image preview for other frames for which the dust removal level is applied are erased.

FULL-SCREEN VIEW

Pressing the Full-screen view button displays the entire corrected image to which the Pixel Polish tab is applied.
