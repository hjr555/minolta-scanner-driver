EXPOSURE CONTROL

Exposure control is used to adjust the amount of exposure for the Master, R, G, and B channels, respectively.
The amount of exposure is adjusted by dragging the slider or entering numeric values into the text box.

<Procedure>

  1. In order to scan negative films, select the exposure control for negatives in the preferences.
  2. Click the Prescan button to execute prescanning.
  3. Click the Exposure Control tab to open.
  4. Set the exposure control value and press the Apply button.
    • An exposure control simulation image is displayed according to the settings.
  5. Press the Scan button in the main window.
    • The image is scanned according to the settings on the Exposure Control tab.

CONFIRMING EXPOSURE CONTROL

When a exposure control value is set and the Apply button is pressed, the exposure control simulation image is displayed according to the setting.

APPLYING EXPOSURE CONTROL TO ALL FRAMES

The current exposure control setting is applied to all frames by pressing the Apply to all frames button.
The prescan image of other frames to which the setting is applied are erased.
This function is invalid for the film format with which the index tab is not displayed.

RESETTING EXPOSURE CONTROL

Clicking the Reset button returns the exposure control values to all 0.
In order to reset all frames, press the Reset button and then press the Apply all frames button.

SAVING EXPOSURE CONTROL VALUE

Clicking the Save button to open the save as dialog box for the current exposure control value.
The saved exposure control value can be read by pressing the Load button.

LOADING EXPOSURE CONTROL VALUE

Clicking the Load button loads the saved exposure control value and applies it on the exposure control tab.
