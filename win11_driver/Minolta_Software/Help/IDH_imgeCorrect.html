IMAGE CORRECTION

TONE-CURVE AND HISTOGRAM CORRECTION

Click the tone-curve/histogram button to display the tone-curve/histogram dialog box. The tone curves are displayed at the top of the dialog box, the histogram is displayed at the bottom.

The tone curves and histogram allow corrections to be made to the contrast, brightness, and color balance of the image. The tone curve and histogram are linked so a change in one will make a corresponding change in the other.

<How to use the tone curve>

  1. Click on the arrow next to the channel list box to display the channels: R, G, B, RGB.
    • When scanning color film, all four channels can be selected. When scanning black and white film, only the RGB channel can be selected.
  2. Select the appropriate channel to correct the image.
    • To change the brightness or contrast of the image, select the RGB channel. To change the color balance, first determine the color cast of the image. It the image is too blue or yellow, select the blue (B) channel. If the image is too red or cyan, select the red (R) channel. If the image is too green or magenta, select the green (G) channel.
  3. Place the mouse pointer over the tone curve. Click and drag the curve.
    • Each time the tone curve is clicked, a new node will be attached to the curve. The tone curve can be adjusted by clicking and dragging the nodes.
    • The input and output levels of the mouse position are displayed.
    • All corrections are applied to the prescan image.

CHANGING THE TONE CURVE BY FREEHAND

This function allows the tone curves to be drawn with the mouse.

<How to change the tone curve>

  1. Select the channel (R, G, B, RGB) to be corrected from the channel list box.
  2. Click the freehand curve button.
    • The cursor will change to the pencil shape.
  3. Draw a new tone curve by clicking and dragging on the graph.
    • To smooth the curve, click the smooth curve button. Nodes will be automatically placed on the curve and can be adjusted with the mouse. With extreme freehand curves, the smooth curve button may significantly change the shape of the curve; press the undo button to return to the original freehand curve.
    • The change will be reflected in the prescan image.

WHITE, BLACK, AND GRAY POINT CORRECTIONS

Advanced image corrections can be made by specifying the white, black, and gray points within the image. Locating an appropriate neutral area within the image is critical to correctly calibrate the software. When the dropper tool is selected, the RGB display is active and can be used to evaluate the image area.

<How to calibrate the software>

  1. Click the white-point button.
    • The mouse pointer will change to the white dropper tool.
  2. Click on the brightest neutral area of the image to define it as the white point.
    • The values in the image will be adjusted based on the selected point. The default level for the white point is 255 for each RGB channel. To change the default white-point value, see the following section.
    • The change will be reflected in the prescan image.
  3. Click the black-point button.
    • The mouse pointer will change to the black dropper tool.
  4. Click on the darkest neutral area of the image to define it as the black point.
    • The values in the image will be adjusted based on the selected point. The default level for the black point is 0 for each RGB channel. To change the default black-point value, see the following section.
    • The change will be reflected in the prescan image.
  5. Click the gray-point button.
    • The mouse pointer will change to the gray dropper tool.
  6. Click on a neutral area of the image to define it as the gray point.
    • The area used to calibrate the gray point must be neutral. The brightness level of the area is not important, but if the area has a definate color, the image will not be color balanced correctly.

SETTING THE WHITE AND BLACK POINT VALUES

The white and black point values are set to 255 and 0 for each RGB level. Changing these values allow the calibration of an image with no true black or white. This is an advanced image-processing tool.

<How to change the white and black point values>

  1. Double-click on either the white-point or black-point button.
    • The point value setting dialog box will be displayed.
  2. Input the new white-point and black-point values. Click "OK" to set the values.
    • With the point value setting dialog box open, the mouse pointer can be used to measure the color of any point on the prescan image. The RGB display shows the original values for the image on the left and the current values on the right.
  3. Calibrate the image following the steps in the previous section.

VIEWING TONE-CURVE CORRECTIONS ON THE HISTOGRAM

Simply click and hold the apply button to view the effect of tone-curve corrections on the histogram. When the button is released, the histogram of the original image will be displayed.

<How to use the histogram>


The input slide bar has a white highlight slider (right), a gray gamma slider (middle), and a black shadow slider (left). The output slide bar has a white highlight slider (right) and a black shadow slider (left). The image can be corrected by dragging the sliders or entering the values in the text boxes next to the histogram.
  1. Drag the slider to adjust the levels or enter the values in the text box next to the histogram.
    • All changes will be reflected in the prescan image.
    • The gamma slider defines the mid-tones of the image. Dragging the gamma slider to the right will darken the image, and dragging it to the left will brighten the image.
    • The input highlight slider sets the white level. All pixels to the right of the slider are set to 255 (white) and any image detail they may contain is lost. Moving the slider to the left increases the apparent contrast of the image.
    • The input shadow slider sets the black level. All pixels to the left of the slider are set to 0 (black) and any image detail they may contain is lost. Moving the slider to the right increases the apparent contrast of the image.
    • The output highlight and shadow sliders can be adjusted. Moving the sliders decreases the apparent contrast of the image.

DISPLAYING THE RGB COLOR CHANNEL HISTOGRAMS

Located just above the tone curve, the histogram RGB display button extends the tone curve and histogram dialog box to reveal the histograms for each color channel. The color histograms can be used to adjust the color balance of the prescan image. Clicking histogram RGB display button again hides the color histogram display.

TONE CURVE AND HISTOGRAM AUTO-SETTING BUTTON

Clicking the auto-setting button automatically corrects the image. The darkest pixels in the image are set to a black level of 0. The brightest pixels are set to a white level of 255. The remaining pixels are distributed evenly between them. To view the change with the histogram, press the apply button.

BRIGHTNESS, CONTRAST, & COLOR-BALANCE CORRECTIONS

Simply click the brightness, contrast, and color-balance button to display the dialog box. Corrections are made by simply dragging the sliders or entering the required value in the text box.

<About brightness, contrast, and color-balance corrections>

    • Brightness controls how light or dark the image is.
    • Contrast controls the difference between the light and dark tones of the image. The apparent sharpness of the image is also influenced by contrast.
    • The red, green, and blue sliders control the overall color of the image. To change the color balance, first determine the color cast of the image. It the image is too blue or yellow, adjust the blue slider. If the image is too red or cyan, adjust the red slider. If the image is too green or magenta, adjust the green slider.
    • All changes will be reflected in the prescan image.

BRIGHTNESS, CONTRAST, & COLOR-BALANCE AUTO-SETTING BUTTON

When the auto-setting button is clicked, the brightness and contrast of the image are corrected automatically. The color balance is not affected.

HUE, SATURATION, AND LIGHTNESS CORRECTIONS

Simply click the hue, saturation, and lightness button to display the dialog box. Corrections are made by simply dragging the sliders or entering the required value in the text box. These controls adjust the image in reference to the HSB color model; the HSB color model defines color based upon human perception rather than photographic processes. This palette can be used to manipulate an image rather than creating a realistic representation.

<About hue, saturation, and lightness corrections>

    • The hue control is not a color-balancing tool. It is a creative tool. When adjusting the hue, each color in the image is assigned a new hue depending on the degree of rotation through the@HSB color space.
    • Saturation controls the how vivid the colors are in the image.
    • Lightness controls how light or dark the image is. Unlike the brightness control in the brightness, contrast, and color-balance palette, the lightness control does not change the apparent density of the colors equally.
    • The palette shows two color samples under the controls. The upper sample is the original color space. The lower sample indicates the change in the color space compared to the original sample.
    • All changes will be reflected in the prescan image.

HUE, SATURATION, & LIGHTNESS AUTO-SETTING BUTTON

When the auto-setting button is clicked, the saturation of the image is corrected automatically. The hue and lightness are not changed.

VARIATION CORRECTIONS

Variation dialog box allows an image to be corrected by comparing it to other slightly corrected images surrounding it. This is an easy method to correct images for individuals who are inexperienced in image processing or photofinishing.

<How use the variation dialog box>

  1. Click the variation button.
    • The variation dialog box will be displayed.
  2. Click the arrow on the left of the variation list box to select the image quality to be adjusted.
    • Color balance, brightness and contrast, and saturation can be selected. If color balance is selected, a seven-image display will appear. If brightness and contrast is selected a nine-image display will appear. If saturation is selected, a three-image display will appear.
  3. Adjust the variation step slider to set the degree of correction between the central image and the surrounding images.
    • The central image is the uncorrected prescan image. The amount of correction set with the slider is reflected in the surrounding images.
    • Click the display-limit box to show when the correction shifts any part of the image outside the brightness range of 0 to 255. The area outside this range with be displayed in the reverse tone or color.
  4. Click on the best image among the surrounding frames.
    • The central prescan image will be replaced by the chosen frame and the surrounding images will adjust accordingly. The amount of correction set with the slider is reflected in the surrounding images. Continue choosing variation images until the central image reflects the desired result.
  5. Close the variation dialog box to apply the correction to the prescan image.

SELECTIVE-COLOR CORRECTIONS

Simply click the selective-color button to display the dialog box. Corrections are made by simply dragging the sliders or entering the required value in the text box. The selective-color palette allows specific colors to be adjusted rather than changing the overall color cast of the image. For example, if the blue of the sky looks purplish, magenta can be subtracted from the blue color group with out affecting the other colors in the image.

<How to use the selective-color palette>

  1. Use the color list box at the top of the palette to select the color to be adjusted.
    • Red, green, blue, cyan, yellow, and magenta color groups are listed.
  2. Drag the Cyan (C), Magenta (M), Yellow (Y) or Black (K) slider or input the desired value in the text box to adjust the selected color.

UNSHARP MASK

Simply click the unsharp-mask button to display the dialog box. Corrections are made by simply dragging the sliders or entering the required value in the text box.

The unsharp mask sharpens edges in the image without affecting the overall contrast of the image. the effect of the unsharp mask is very subtle, but makes a significant improvement to the overall appearance of the image.

The effect of the unsharp mask cannot be viewed in the prescan image. It can only be seen in the final scan.

<About the unsharp mask>

    • Amount: can be adjusted between 0% and 500%. Adjusting the slider increases the level of contrast. If the value is too high, pixelation, a rough or grainy texture on the image, will be apparent. 150% to 200% is recommended for high quality printed images.
    • Radius: can be adjusted between 0.1 and 5. The default setting is 1. Adjusting the slider increases the edge sharpness of the pixels. A radius of 1 or 2 is recommended for high quality printed images. Changes to the radius are more apparent on printed images than images displayed on a monitor.
    • Threshold level: can be adjusted between 0 and 255. The default setting is 2. If the difference between the surrounding pixels is greater than the threshold level, that pixel is recognized as a sharp image pixel. When the level is set to 0, the whole image is sharpened. The threshold level can protect smooth gradations from edges and details to be sharpened.
    • Shadow protection level: can be adjusted between 0 and 255. The default setting is 16. To limit the sharp pixels in the shadows. When the luminance level is greater than the shadow protection level, that pixel is recognized as a sharp pixel.

UNDOING IMAGE CORRECTIONS

Simply click the undo button to cancel the last image correction.

REDOING IMAGE CORRECTIONS

Simply click the redo button to apply a canceled image correction.

RESETTING AN IMAGE-CORRECTION DIALOG BOX

Simply click the reset button on the dialog box to reset all the corrections made.

STORING IMAGE CORRECTIONS TEMPORARILY

When the snapshot button is clicked, the current prescan image is stored as a thumbnail in the snapshot display area. Multiple snapshots can be stored while processing an image. To return to a specific set of corrections, simply click the snapshot.

COMPARING PRE AND POST-CORRECTION IMAGES

When the comparison display button is clicked, the image-correction display window is divided into two. The original prescan image is displayed on the left and the corrected image is displayed on the right.

FIT-TO-WINDOW BUTTON

Click the fit-to-window button to display the entire image area in the utility window. As the window is resized, the image will enlarged or reduced automatically.
