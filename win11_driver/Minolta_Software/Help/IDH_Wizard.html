CUSTOM WIZARD

The Custom Wizard automates the scanning procedure. In seven easy steps, the scanner can be setup to produce beautiful scans. Simply press the Custom Wizard button in the main window to launch the Wizard.

1. CUSTOM WIZARD SETTING

Previous Custom Wizard scanner settings can be used or new settings can be made. Select "new" to make a new Custom Wizard setup.

<Procedure>

  1. Select the Custom Wizard setting from the list box.
  2. Click [Next>].

2. SELECT THE FILM TO BE SCANNED

Select the format and type of film to be scanned. The images to be scanned are also selected with this window.

<Procedure>

  1. Select the appropriate film format from the list box.
  2. Select the appropriate film type from the list box.
  3. Click on the frame-number check boxes to select the images to be scanned. The frame numbers correspond to the film-holder frame numbers
  4. Click [Next>].

3. SET SCANNER PREFERENCES

The following items can be set in the preferences dialog box in the Custom Wizard:

AUTO EXPOSE FOR SLIDES

Since well exposed slides are uniform in density, auto exposure control is not needed when scanning. However, when a slide is over or underexposed, the auto-exposure system can compensate for the unusual density. Simple click the check box to use auto exposure with slide film.

AUTOFOCUS AT SCAN

Checking this option activates the autofocus system during the scan. The autofocus-at-scan option increases the scanning time.

COLOR DEPTH

This option specifies the color depth of the scanned image. Three options are available: 8 bit, 16 bit, and 16-bit linear. 16-bit linear does not make any gamma corrections so a scanned negative will produce a negative image. 16-bit and 16-bit linear images can only be saved as TIFF files. Some image-processing applications, like Adobe Photoshop Elements, cannot process 16-bit image files.

MULTI-SAMPLE SCANNING

Multi-sample scanning reduces random noise in the image by analyzing the data of each sample scan. The more samples taken, the less random noise and the longer the scanning time. There are five multi-sample settings: off, 2X, 4X, and 8X.

COLOR MATCHING

Each output device (monitor or printer) defines color and contrast differently. To ensure the reproduction of the image on the monitor matches the reproduction of the image from the printer, the color space for both devices must be defined.

The scanner's color-matching function matches the color and contrast of the scanned image with the specified output color space. The color matching system can use the monitor's ICC profile to display the image as accurately as possible. For more details on color matching, refer to the instructions in the preferences section.

ROTATE ALL INDEX FRAMES 180 DEGREES - FOR APS FILM ONLY

Simply click the check box to rotate the APS images 180 degrees.

<Procedure>

  1. Select the desired scanner preferences and click [Next>].

4. SCAN SETTINGS

The input and output resolution and size of the image to be scanned can be set. The auto-cropping function automatically eliminates blank space from around the image area.

INPUT RESOLUTION LIST BOX

Values can be selected from the drop-down list or entered directly into the box. The resolutions on the list are 2820, 1410, 940, 705, 470, 352, and 282. The default setting is 705.

OUTPUT RESOLUTION LIST BOX

Values can be selected from the drop-down list or entered directly into the box. The output resolution options are 2400, 1440,1200, 800, 720, 600, 400, 360, 350, 300, 240, 200, 180, 150, 96, 72, and 36 dpi. Values between 36 and 2400 can be enter into the box. The default setting is 300 dpi. The output resolution list box cannot be selected while "pixel" is selected in the unit list box.

INPUT SIZE TEXT BOX

The input size is related to the the cropping frame. As the cropping frame is adjusted the input size will change. Entering values for the input size will adjust the cropping frame to the new dimensions. The input size text box cannot be used while "pixel" is selected in the unit list box.

Click the lock button next to the input size text box to set the dimensions. The cropping frame can be moved when the input size is locked, but it cannot be resized. Clicking the button again releases the lock.

MAGNIFICATION TEXT BOX

The magnification of the input image to the output image is set in this box. Magnification is calculated by the input resolution divided by the output resolution, or the output size divided by the input size.

When the input and output size are not locked, the input resolution and output size vary according to the magnification value entered. When the output size is locked, the input resolution and size will vary with the change in magnification. When the input size is locked, the input resolution and output size vary with the change in magnification. Magnification cannot be adjusted when "pixel" is selected in the unit box.

OUTPUT SIZE TEXT BOX

The output size is related to the size of the cropping frame, and the input and output resolution. The width and height of the image can be directly entered into the text boxes; the input resolution and size, and the cropping frame will adjust accordingly.

The output size can be locked by clicking the lock button next to the text boxes. The cropping frame can be resized, but its dimensions will be proportional to the output size. When adjusting the cropping frame the input resolution and size adjust accordingly. Clicking the button again releases the lock.

UNIT LIST BOX

The unit of the input and output sizes can be specified: pixels, millimeters, centimeters, inches, pica, and point. The default setting is pixels.

IMAGE SIZE DISPLAY

This indicates the file size of the image based on the scanner settings.

<Procedure>

  1. Select auto cropping to eliminate blank space around the image.

    • The inside edge cropping crops the image just inside the image area. The outside edge cropping crops the image just outside the image area. Inside edge cropping is recommended for mounted slides.
  2. Set the input and output resolution and size.
  3. Click [Next>].

5. AUTO DUST BRUSH/PIXEL POLISH SETTINGS

You can set whether the Auto Dust Brush and Pixel Polish functions are used.
For details of each function, see the explanation in Auto Dust Brush and Pixel Polish.

<Procedure>

  1. Click the function you want to use and click [Next>].
    The Exposure Control screen appears.

6. EXPOSURE CONTROL

Used to set the exposure control value.
For details of EXPOSURE CONTROL, refer to the explanation for EXPOSURE CONTROL.

<Procedure>

  1. Set the exposure control value and click [Next>].

7. IMAGE CORRECTION

The image correction can be made by loading an image-correction Job or by using the auto-setting functions. For details on image-correction Jobs, refer to the instructions in the saving and loading image-correction Jobs section.

The auto-setting functions automatically correct the scanned image. The tone curve and histogram setting improves color and contrast. The brightness, contrast, and color balance setting improves contrast and brightness. The hue, saturation, and lightness setting improves the saturation of the colors.

<Procedure>

  1. Select the image-correction options and click [Next>].

8. END OF SETUP

The Custom Wizard settings made can be save and used again.

<Procedure>

  1. Click [Save].
  2. Input the name for the Custom Wizard settings. Click [OK].
  3. Click [Start] to begin scanning.

TO CONTINUE SCANNING

When the scanner has finished scanning, a new window will be displayed. Click [Start] to continue scanning with same settings, or click [Quit] to end the scanning session.
